키워드 30개를 뽑는 시트

판정 두 칸은 수식이 이미 들어 있습니다. 당신이 채우는 칸은 다섯 개뿐입니다.

키워드금고 템플릿 받기 CSV · 50행

1. 시트 열기

  1. sheets.google.com → 빈 스프레드시트 만들기
  2. [파일] → [가져오기] → [업로드] 탭에 받은 CSV를 끌어다 놓기
  3. 가져오기 위치 "현재 시트 바꾸기", 구분자 "자동 감지" → [데이터 가져오기]

엑셀에서도 열리지만 수식은 구글 시트에서만 자동 계산됩니다. 시트를 권합니다.

2. 채우는 순서

칸넣는 것어디서
A 키워드수확한 키워드 하나씩네이버 자동완성·연관검색어
B 출처자동완성 연관 직접어디서 주웠는지
C 월간검색수PC + 모바일 합산 숫자searchad.naver.com → 도구 → 키워드 도구
D 검색수판정— 자동 — 100 미만 탈락 · 100~1,000 황금 · 1,000~5,000 채택 · 초과 보류
E 점령자공식 매체 블로그 부실네이버에서 실제 검색
F 경쟁판정O △ X (둘 다 O면 OO)아래 판정표
G 추세상승 유지 하락datalab.naver.com (선택)
H 채택— 자동 — [황금·채택] + [O·OO] → Y, 그 외 N

경쟁판정표 (F열에 넣을 값)

1페이지에 뭐가 있나F뜻
공공기관·공식 사이트·뉴스·대형 매체가 다수X권위로 밀린다. 비집을 틈이 없다
2년 이상 지난 글, 질문글, 부실한 문서가 다수O콘텐츠 공백. 제대로 쓴 글 하나로 이긴다
개인 블로그·카페인데 품질이 좋음△이길 수 있으나 글 품질 승부
네이버도 구글도 OOO최우선
통과 게이트 — 끝났는지는 느낌이 아니라 이 셋으로 확인합니다 A열에 키워드 50개 이상 · C열 검색수 빈칸 없음 · H열 Y가 30개 이상
Y가 모자라면 접미어(방법·후기·비용·가격·추천·비교·차이·순서·기간·조건·서류·실패)와 대상어(초보·직장인·자취·아기·40대·소자본·무자본·지역명)를 조합해 더 수확하세요.

3. 막혔을 때

D·H열에 수식이 글자로 보인다
엑셀에서 연 경우입니다. 구글 시트로 가져오세요.
검색광고 가입이 안 된다
사업자 없이 개인으로 가입됩니다. 광고를 집행하지 않아도 키워드 도구는 무료입니다.
검색수가 전부 100 미만이다
주제가 너무 좁습니다. 상위 주제어로 한 단계 올라가 다시 수확하세요.
전부 X로 나온다
헤드 키워드만 모은 경우입니다. 3어절 이상 롱테일로 다시 보세요.
Y가 30개를 훌쩍 넘는다
황금(100~1,000) + OO부터 위로 30개만 남기세요. 나머지는 2~3개월 차 재고입니다.
