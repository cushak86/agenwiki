## 청소년한부모 자립촉진수당 월 10만 원

- 부산광역시 한부모가족 지원 페이지에서 "자립촉진수당" 항목 확인: "소득인정액이 기준 중위소득 65% 이하인 가족으로서 '부' 또는 '모'가..." 월 10만 원 지급
- 울산광역시 페이지에서도 청소년한부모 자립촉진수당 월 10만 원 확인
- 여성가족부 본 페이지에는 아동양육비·추가양육비·교육지원비·생활보조금만 명시, 자립촉진수당은 지자체 페이지에서 확인
- 주의: 여성가족부 메인 페이지에 자립촉진수당이 명시적으로 없으나, 지자체 공식 페이지에 일관되게 기재됨
