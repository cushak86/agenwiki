## 주의 / 사람이 재확인할 항목

1. **일반 버팀목 금리표 셀 값**: 공식 포털 표가 동적 로딩이라 KB국민은행 상품설명(국토부 고시 인용)으로 채움. 범위는 공식 요약과 일치하지만 셀별 수치는 기금포털 화면에서 한 번 더 확인 권장.
2. **수탁은행 목록**: N4는 "대구은행", M1은 "iM뱅크"로 표기. 본문은 "우리·국민·신한·하나·농협 등"으로만 씀.
3. **중기청 대출 신규 취급 종료 시점**: 공식 페이지에서 종료일 문구를 찾지 못함. 본문은 "현재 상품 목록에 별도 상품이 없다"와 청년전용 내 우대금리 사실만 서술.
4. **DSR**: 2026-10-07 기준 버팀목 DSR 적용 발표는 확인되지 않음. 금융위가 '검토' 중이라 향후 바뀔 수 있음.
5. 2025-02 금리 0.2%p 인상(지방 제외)은 언론(한국세정신문 2025-02-24)·KB 변경이력으로만 확인돼 본문에서는 뺐음.
