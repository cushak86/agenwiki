# 사실 검증: housing-subscription-deduction (청약통장 소득공제)

검증일: 2026-11-11

## 핵심 수치

| 수치 | 근거 | 확인 내용 |
|---|---|---|
| 총급여 7,000만 원 이하 근로자 대상 | 조세특례제한법 제87조 제2항 (법률 제21467호) + 국세청 안내 | "총급여액이 7천만원 이하" 법조문과 국세청 모두 동일 |
| 연 납입한도 300만 원, 공제율 40%, 최대 120만 원 | 조세특례제한법 제87조 제2항 "연 300만원을 납입한도로 하며 … 100분의 40에 상당하는 금액" + 국세청 "연 납입액 300만원 한도의 40% 소득공제" | 300만 × 40% = 120만 원 |
| 적용기한 2028.12.31 납입분까지 | 조세특례제한법 제87조 제2항 "2028년 12월 31일까지" | |
| 세대주 또는 배우자 (2025.1.1 이후 납입분부터 배우자 추가) | 조세특례제한법 제87조 제2항 "세대주등" + 국세청 안내 "2025.1.1.이후 납입하는 분부터 배우자도 공제혜택 부여" | |
| 무주택확인서 다음 해 2월 말까지 제출 | 조세특례제한법 제87조 제4항 제1호 "소득공제 적용 과세기간의 다음 연도 2월 말까지" + 국세청 | |
| 과세기간 중 무주택 세대 | 조세특례제한법 제87조 제2항 "해당 과세기간 중 주택을 소유하지 않은 세대" | 12.31 기준이 아니라 연중 전체 |
| 청년우대형 이자소득 500만 원 비과세, 납입한도 연 600만 원 | 조세특례제한법 제87조 제3항 "이자소득의 합계액에 대해서는 500만원까지 소득세를 부과하지 아니한다. 납입금액을 합하여 연 600만원을 한도" | |
| 청년우대형 소득기준: 총급여 3,600만 원 이하 또는 종합소득 2,600만 원 이하 | 조세특례제한법 제87조 제3항 제1호 가·나목 | |
| 주택임차차입금 합산 한도 연 400만 원 | 다수 세무 정보 사이트(머니샐러리, 지원금허브) 일치 | **주의**: 법 조문에서 직접 "400만 원"을 명시한 부분은 소득세법 시행령 제112조. 관행적으로 알려진 한도이나 본문에서 확인 권유 |
| 해지 시 추징 가능성 | 다수 세무 사이트 + 핀픽 "5년 내 해지는 추징 여부를 확인" | 국세청 공식 안내에서 구체적 추징세율 6.6%는 직접 확인하지 못함. 본문에서 "추징 가능성"으로 표현, 세무 전문가 확인 권유 |

## 주의

- "과세기간 중 무주택 세대" 요건은 12.31 하루만이 아닌 연중 전체를 의미. 연중 주택 취득 후 처분한 경우의 공제 가능 여부는 개별 판단 필요 → 본문에서 국세청/세무사 확인 권유로 처리.
- 합산 한도 400만 원은 소득세법 시행령 제112조 참조. 본문에서 이 수치를 언급하면서 확인을 권유.
- 해지추징세율 6.6%는 관행적으로 인용되지만 법 조문 직접 확인 미완. 본문에서 "추징 가능성이 있습니다"로 보수적 표현.
