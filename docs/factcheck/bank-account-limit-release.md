# 사실 검증: bank-account-limit-release (한도제한계좌 해제 방법)

검증일: 2026-11-10

## 핵심 수치 검증

### 현행 1일 거래한도 (2024.5.2 상향)
- 창구 300만 원, ATM 100만 원, 인터넷·모바일뱅킹 100만 원
- 종전: 창구 100만 원, ATM 30만 원, 전자금융 30만 원
- **근거:** 금융위원회 보도자료 (2024.5.2, fsc.go.kr/no010101/82205) — "한도제한 계좌를 보유한 고객은 하루에 ▴인터넷뱅킹 100만원 ▴ATM 100만원 ▴창구거래 300만원 까지 거래할 수 있게 된다"
- **교차확인:** KDI 경제정보센터 (eiec.kdi.re.kr) 동일 보도자료 PDF 확인 — 한도 상향 표 동일

### 한도제한계좌 도입 시기: 2016년
- **근거:** 금융위원회 보도자료 — "금융거래 목적 확인에 필요한 객관적 증빙 서류를 제출할 수 없어 입출금 통장 개설이 곤란했던 은행이용자를 위해 '16년에 도입된 계좌이다"

### 금융거래 목적 확인 제도: 2012년 시행
- **근거:** 금융위원회 보도자료 — "대포통장 근절을 위해 입출금 통장 개설시 금융거래 목적을 확인하도록 하는 제도('12년 시행)"

### 인터넷전문은행 한도: 종전과 동일 (ATM·전자금융 100만~200만 원)
- **근거:** 금융위원회 보도자료 — "인터넷전문은행의 한도제한 계좌 거래한도는 종전과 동일 (ATM‧전자금융:100만원~200만원)"

### 기존 한도제한계좌 자동 상향 적용
- **근거:** 금융위원회 보도자료 — "상향 한도는 고객이 별도로 신청할 필요 없이 기존의 한도제한 계좌에도 적용되고, 일괄 상향에 동의하지 않는 고객은 거래 은행에 별도로 신청하여 기존 한도를 유지할 수 있다"

### 해제 증빙서류 예시 (목적별)
- 급여: 재직증명서, 급여명세표, 근로소득원천징수영수증, 건강보험자격득실확인서
- 사업: 사업자등록증, 세금계산서, 매출거래계약서
- 연금: 연금증서, 수급권자 확인서
- **근거:** 금융위원회 보도자료 — "금융거래 목적별 대표 증빙서류 안내장 마련", KB국민은행 공식 안내 (2026.2.24 기준) — 증빙서류 목록, 하나은행 공식 안내 — 비대면 해제 조건 및 서류

### 공공마이데이터 활용 비대면 해제
- **근거:** 금융위원회 보도자료 — "금융거래목적 확인에 공공마이데이터 등을 활용함으로써 절차를 간소화"
- **교차확인:** 하나은행 공식 안내 — "공공마이데이터를 이용해 필요한 정보를 불러오기 때문에 별도로 서류를 제출하지 않아도 신청할 수 있습니다"

### 법적 근거
- 특정 금융거래정보의 보고 및 이용 등에 관한 법률(특금법) 제5조의2
- 전기통신금융사기 피해 방지 및 피해금 환급에 관한 특별법 (2024.8.28 개정·시행)
- **근거:** 금융위원회 보도자료 및 KB국민은행 공식 안내에서 법률 인용 확인

### 금융소비자 통합 콜센터: 1332
- **근거:** 금융감독원 파인 (fine.fss.or.kr) 메인 페이지 — 콜센터 1332 표시 확인

## 불확실한 점
- 증빙서류 목록은 금융위원회와 주요 은행 안내 기준의 '통상 예시'이며, 은행·지점마다 요구 서류가 다를 수 있음을 본문에 명시함.
- 급여이체 3개월 연속(건당 150만원 이상) 등 실적 기반 자동 해제 조건은 특정 은행(국민·신한 등) 안내에서 확인한 예시이며 전 은행 공통 기준이 아님을 본문에 명시함.
- 비대면 해제 성공률과 소요기간은 은행 내부 심사에 따라 다르며 공개 기준이 없음.
