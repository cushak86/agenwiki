## 계산 검산 (2026 요율)
- 예시1 (200만 원)
  - 근로자: 고용 2,000,000×0.9%=18,000 → ×80%=14,400 / 연금 2,000,000×4.75%=95,000 → ×80%=76,000 / 합 90,400. 본인부담 (18,000+95,000)−90,400=22,600
  - 사업주: 고용 2,000,000×1.15%=23,000 → 18,400 / 연금 76,000 / 합 94,400. 부담 (23,000+95,000)−94,400=23,600
  - 36개월: 90,400×36=3,254,400 / 94,400×36=3,398,400 / 합 6,652,800
- 예시2 (250만 원, 230만 원 기준 상한)
  - 근로자 지원 103,960(=16,560+87,400). 실제보험료 2,500,000×0.9%=22,500 + 2,500,000×4.75%=118,750 = 141,250 → 부담 37,290
  - 사업주 지원 108,560(=21,160+87,400). 실제 2,500,000×1.15%=28,750 + 118,750 = 147,500 → 부담 38,940
  - 36개월: 103,960×36=3,742,560 / 108,560×36=3,908,160 / 합 7,650,720
- 2025 비교: 2,300,000×4.5%×80%=82,800 ✓, 근로자 16,560+82,800=99,360 ✓, 사업주 21,160+82,800=103,960 ✓
