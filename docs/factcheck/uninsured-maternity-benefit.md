# 팩트체크: 고용보험 미적용자 출산급여

검증일: 2026-10-26

## 핵심 수치

| 수치 | 근거 | 확인 |
|---|---|---|
| 총 150만원 일괄 지급 (월 50만원 × 3개월) | 정부24 서비스 안내 (최종수정 2026.05.08) + 고용보험 누리집 + 고용노동부 정책자료실 | ✅ 3개 출처 일치 |
| 신청 기한: 출산일로부터 1년 이내 | 정부24 + 고용보험 누리집 | ✅ 2개 출처 일치 |
| 지급 결정: 접수 후 14일 이내 | 정부24 + 고용보험 누리집 | ✅ |
| 유산·사산 지급액: 15주 이하 30만원, 16~21주 50만원, 22~27주 100만원, 28주 이상 150만원 | 정부24 + 고용보험 누리집 | ✅ 2개 출처 일치 |
| 소득활동 요건: 출산 전 18개월 중 3개월 이상 | 고용보험 누리집 | ✅ |
| 2026년 변경: 세금 신고된 소득 기준 인정 (2026.2.1 신청분부터) | 정부24 + 고용노동부 정책자료실 (2025-12-31 등록) | ✅ 2개 출처 일치 |
| 보조인력: 임신 진단 이후 채용 1인 허용 | 정부24 + 고용노동부 정책자료실 | ✅ |
| 특고·프리랜서: 배우자·동거친족 사업주면 제외 | 고용노동부 정책자료실 | ✅ |
| 예술인·노무제공자 출산전후급여 대상자 제외 | 복지로 (고용보험법 제77조의4, 제77조의9) | ✅ |
| 특고 9개 직종 | 고용보험 누리집 | ✅ |
| 부동산임대 소득활동 불인정 | 고용보험 누리집 | ✅ |

## 출처 URL

1. https://www.gov.kr/portal/service/serviceInfo/149200000153 (정부24, 최종수정 2026.05.08)
2. https://ei.work24.go.kr/ei/eim/eg/ei/eiEminsr/retrievePb0304Info.do (고용보험 누리집)
3. https://www.moel.go.kr/policy/policydata/view.do?bbs_seq=20251201768 (고용노동부 정책자료실, 2025-12-31 등록)
4. https://www.bokjiro.go.kr/ssis-tbu/twataa/wlfareInfo/moveTWAT52011M.do?wlfareInfoId=WLF00000838 (복지로)

## 주의

- 법적 근거: 저출산·고령사회기본법 제10조로 정부24에 표기되나, 정확한 조·항 번호가 깨져 있어 원문 확인 필요. 고용보험법이 아닌 고용노동부 예산 사업으로 운영되는 것으로 보임.
- 다태아·둘째 이상 별도 가산금: 확인한 출처 어디에서도 별도 가산 규정 없음. 모두 150만원 일괄.
- 고용24 vs ei.go.kr: 정부24는 고용24로 안내, 고용보험 누리집은 www.ei.go.kr로 안내. 고용24가 현행 통합 플랫폼.
