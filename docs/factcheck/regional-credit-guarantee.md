## 출처 간 충돌

- **보증비율**: 85~100% 범위는 재단별·상품별로 다를 수 있음. 시행령에 구체 비율 명시 없고, 각 재단 자체 규정에 따름. "85~100%"는 중앙회 통합 안내와 다수 재단 공통 범위.

## 불확실한 점

- 보증비율 85~100%: 시행령이 아닌 각 재단 내부 규정으로 결정되므로, 재단별 차이가 있을 수 있음. 본문에 "85~100%"로 범위 표기.
