## 주의

- 2012년 7월 1일 이후 등록자에게는 6급 3항(월 119만 4천 원)이 별도로 존재. 본문 표에서는 2012.7.1 이후 기준을 별도 표기하지 않고 주요 등급만 수록.
- 독립유공자 보상금(건국훈장 1~3등급 792만 4천 원 등)은 본문에 간략 언급. 상세 금액은 국가보훈부 PDF 참조.
- 보상금 외 수당(전상수당 9만 원, 고령수당 9만 7천 원 등)은 국가보훈부 블로그·나만의예우찾기에서 확인했으나 별표 원문 PDF(hwp)를 직접 열어보지는 못함. 금액에 오차 가능성은 낮으나 추후 직접 PDF 확인 권장.
- 고엽제후유의증수당(62만 6천~129만 6천 원)은 oneulmohae.com 기준으로 교차 확인함.
