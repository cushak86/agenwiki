## 계산 예시 검산

### 예시 1: 연 수입 2,000만원, 단순경비율 64.1%
- 필요경비: 2,000만 × 64.1% = 1,282만원 ✓
- 사업소득금액: 2,000만 - 1,282만 = 718만원 ✓
- 과세표준: 718만 - 150만(기본공제) = 568만원 ✓
- 산출세액: 568만 × 6% = 34.08만원 ✓ (1,400만원 이하 6% 구간)
- 결정세액: 34.08만 - 7만(표준세액공제) = 27.08만원 ≈ 27만원 ✓
- 원천징수: 2,000만 × 3% = 60만원 ✓
- 환급: 60만 - 27만 = 약 33만원 ✓

### 예시 2: 연 수입 1,000만원, 단순경비율 64.1%
- 사업소득금액: 1,000만 × 35.9% = 359만원 ✓
- 과세표준: 359만 - 150만 = 209만원 ✓
- 산출세액: 209만 × 6% = 12.54만원 ✓
- 결정세액: 12.54만 - 7만 = 5.54만원 ≈ 5.5만원 ✓
- 원천징수: 1,000만 × 3% = 30만원 ✓
- 환급: 30만 - 5.5만 = 약 24.5만원 ✓

## 주의

- 단순경비율 64.1%는 업종코드 940909(기타자영업) 기준이며, 업종마다 다릅니다. 본문에 "업종별 경비율에 따라 달라진다"고 명시함.
- 소득세율표(6%~45%)는 2025년 귀속 기준으로 변동 없음 확인 필요 (2024년 대비 변경 없음).
