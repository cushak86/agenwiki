- 8,000만 − 2,000만 = 6,000만 / ×60% = 3,600만 → 4,400만, ÷120 = 366,667원 ✔
- ×30% = 1,800만 → 6,200만, ÷120 = 516,667원 ✔
- ×90% = 5,400만 → 2,600만, ÷240 = 108,333원 ✔

## 주의
- **신청기한 연장 여부**: 공식 근거는 "2026년 말까지"([H])뿐. 일부 법률사무소·블로그가 "2026년 6월 금융위가 2027년까지 연장 발표"라고 쓰지만, 금융위 2026.6.25 보도자료 원문([F])에는 연장 언급이 없음. 2026.10.7 기준 공식 연장 발표 미확인 → 본문에 "미발표"로 기재. 연말 전 재확인 필요.
- **6월 감면기준 차등화 실제 시행일**: 보도자료는 "협약개정 등('26.6월말)"로만 표기. 새출발기금 공지에 시행 확정 공지는 보도자료 게시(2026.6.25)만 확인 → 본문은 "낮아집니다(발표)" 수준으로 기술.
- 예시 1은 순부채 × 감면율을 단순 적용하고 이자를 제외한 설명용 계산. 실제 감면율·상환액은 변제가능률·재산 심사로 결정.
- 캠코 상담창구 수는 FAQ 기준 18개소(일부 민간 글은 26곳으로 표기, 출처 불명).
- 중개형(부실우려차주) 조정 후 적용금리의 일반 수준은 공식 수치 미확인으로 본문 미기재(사회취약계층 30일 이하 연체자 상한 3.9~4.7%는 [G]에 있으나 본문 생략).
