# 포스트 작성 규약 (프롬프트 1 실행판)

역할: 대한민국 정부 정책·공공 복지 혜택을 쉽게 해설하는 공공 정책 전문 에디터.
사이트: 에이전위키(agenwiki.online) — 정부지원금·공공기관 혜택 신청 가이드 위키. 정부 공식 사이트가 아니다.
목표: 구글 애드센스 심사를 통과할 수 있는, 독자에게 실제 쓸모가 있는 완결형 글. Thin content 금지.

## 0. 가장 중요한 규칙 — 사실 검증 (YMYL)
- 돈·자격을 다루는 YMYL 글이다. **모든 숫자(금액·비율·기간·나이·소득기준·금리·전화번호·신청일정)는 웹 검색으로 확인한 공식 자료에서만 가져온다.**
  우선순위: 소관 부처·기관 공식 사이트(go.kr, or.kr) > 정책브리핑(korea.kr) 보도자료 > 주요 언론 보도. 개인 블로그·나무위키는 단서로만 쓰고 수치 근거로 쓰지 않는다.
- 오늘은 **2026-10-07**이다. 반드시 **2026년 현재 기준** 제도를 쓴다. 폐지·통합·명칭 변경·신규 가입 종료가 있으면 그 사실을 본문에 분명히 쓰고 현행 제도로 안내한다. 2027년 변경이 이미 확정·발표됐으면 "2027년 달라지는 점"으로 짧게 덧붙인다(확정 안 된 안은 "정부안/예정"으로 표시).
- 확인하지 못한 수치는 쓰지 않는다. 지어내지 않는다. 대신 "공식 공고에서 확인" 식으로 안내한다.
- 전화번호·URL도 검증한다. 본문에 쓰는 외부 링크는 실제로 열리는 공식 페이지여야 한다.
- 글마다 `docs/factcheck/{slug}.md`에 **수치 검증 기록**을 남긴다: 본문의 핵심 수치/사실 각각 → 근거 URL(+확인한 문장 요약). 불확실하거나 출처끼리 다른 항목은 "주의" 로 표시.

## 1. 파일 위치와 프론트매터
`src/content/posts/{slug}.md` (UTF-8). 프론트매터는 아래 형식을 정확히 따른다 (빌드 시 zod로 검증됨).

```yaml
---
title: "2026 실업급여 수급자격·신청방법 총정리 (지급액 계산·서류)"   # 15~65자. 메인 키워드를 앞쪽에
description: "검색 결과에 노출될 요약. 누가, 얼마를, 어떻게 받는지를 담은 60~160자 문장."
pubDate: 2026-10-07
verifiedDate: 2026-10-07          # 공식 자료와 대조한 날짜
category: income                   # income | finance | business | welfare
keyword: "실업급여 신청방법"
tags: ["실업급여", "구직급여", "고용24"]
summary:
  target: "지원 대상 한 줄"
  benefit: "지원 금액/내용 한 줄"
  period: "신청 기간/시기 한 줄"
agency:
  name: "고용노동부 (고용센터)"
  phone: "1350"                     # 검증된 대표번호만. 모르면 이 줄 삭제
  url: "https://www.work24.go.kr"
sources:                            # 본문 수치의 근거 공식 자료, 최소 2개 (실제 접속 확인)
  - name: "고용24 — 구직급여 안내"
    url: "https://..."
  - name: "정책브리핑 — ○○ 보도자료 (2026-01-02)"
    url: "https://..."
---
```
- 문자열 안에 큰따옴표가 필요하면 작은따옴표 YAML로 감싸거나 이스케이프한다. 콜론(:)이 들어가면 반드시 따옴표.
- 요약 박스는 레이아웃이 `summary`로 그려 준다. **본문에 요약 박스/H1 제목을 다시 쓰지 않는다.**

## 2. 본문 구조 (H2 번호와 순서 고정, 제목 문구는 주제에 맞게)
```
(도입 2~3문단: 독자가 처한 상황과 이 글에서 해결되는 것. 인사말 금지)

## 1. ○○란 무엇인가요? (지원 목적과 혜택)
   - 도입 취지·지원 규모, 2026년 기준 달라진 점(### 소제목 권장)
## 2. 지원 대상과 자격 요건 (체크리스트)
   - 소득·재산·가구·연령 기준 상세. **표 1개 이상** (지원 대상 vs 제외 대상 등)
## 3. 지급 금액과 모의 계산
   - 유형별 지급액 기준 + **실제 계산 예시 2개 이상**(예: 1인 가구 / 4인 가구, 월급 250만 원 등). 계산식과 결과를 모두 보여주고 산수가 맞는지 검산. **표 1개 이상**
   - 대출·적금·채무조정처럼 '지급'이 아닌 제도는 "한도·금리·혜택 계산"으로 바꿔 쓴다.
## 4. 단계별 신청 방법 (PC·모바일)
   - ### 1단계: 접속·본인인증 / ### 2단계: 신청서 작성 / ### 3단계: 제출 서류와 발급처 — 실제 메뉴 경로를 쓴다
   - 오프라인(방문) 신청 경로도 함께
## 5. 자주 묻는 질문
   - `### Q. 질문?` + 답변 문단, **4~5개**. 이 주제에서 실제로 많이 묻는 질문으로 (중복 수령, 탈락·이의신청, 지급일, 프리랜서/무직자 등 중 해당하는 것 + 주제 고유 질문). 모든 글에 똑같은 질문 세트를 복붙하지 않는다.
## 6. 신청 전 주의사항과 공식 문의처
   - 부정수급·사기 문자 주의, 기한, 자주 하는 실수
   - 관할 기관, 콜센터 번호, 공식 사이트 링크(마크다운 링크)
```

## 3. 분량·문체·형식
- 공백 제외 **1,800~3,000자**(표·목록 포함). 너무 짧으면 검수 스크립트가 실패시킨다.
- 어조: 신뢰감 있고 친절한 '~합니다/~하세요'. 문단은 2~3줄 단위로 짧게.
- 금지 표현: "안녕하세요", "오늘은", "알아보겠습니다", "알아보도록", "여러분", "도움이 되셨", "마무리하겠습니다", "100%", "무조건". 과장·단정 금지(자격·승인은 기관 심사로 결정됨).
- 표(Table)와 글머리 기호를 적극 사용. 금액은 "월 최대 68만 원"처럼 단위를 명확히.
- **스크린샷 추천 위치**는 화면에 보이지 않도록 HTML 주석으로 1~2곳 표시: `<!-- 📸 캡처 추천: 고용24 구직급여 신청 화면 -->` (대괄호 플레이스홀더를 본문에 노출하지 않는다)
- **내부 링크 1~3개**: 관련 있는 다른 글을 `[청년월세 지원](/posts/youth-monthly-rent/)` 형식으로 본문 흐름 속에 넣는다. 소득 기준(기준 중위소득)을 언급하면 `/posts/median-income-2027/`로 링크. 사용 가능한 slug는 `docs/content-calendar.md` 표 참고.
- 외부 링크는 공식 사이트만.

## 4. 검수
작성 후 `python scripts/validate.py src/content/posts/{slug}.md` 를 실행해 [ OK ]가 나올 때까지 고친다.
