GraphVid는 텍스트 프롬프트나 궤적 지정 대신 구조화된 상호작용 그래프로 다중 객체의 움직임을 지시하는 이미지-투-비디오 생성 모델이다. 학습 데이터와 학습 파라미터 수를 크게 줄이고도 기존 궤적 기반 모델 Motion-I2V 대비 FID를 최대 39.9%, FVD를 최대 37.6% 낮췄고, PSNR은 9.87에서 15.98로, SSIM은 0.38에서 0.61로 올랐다.

| 항목 | 수치 |
| --- | --- |
| FID 개선폭(Motion-I2V 대비) | 최대 39.9%↓ |
| FVD 개선폭(Motion-I2V 대비) | 최대 37.6%↓ |
| PSNR 변화 | 9.87 → 15.98 |
| SSIM 변화 | 0.38 → 0.61 |

## 1. GraphVid는 어떤 문제를 풀려는 모델인가?

영상 속 여러 객체가 서로 어떻게 상호작용할지를 정밀하게 지정하는 일은 아직 어렵다. 텍스트 프롬프트는 물체 간 관계를 세밀하게 표현하기 어렵고, 궤적 기반 제어는 사용자가 각 객체의 움직임 궤적을 직접 그려야 한다. 장면에 객체가 늘어날수록 이 작업은 급격히 번거로워지고, 객체끼리 겹치거나 가려지면 궤적 자체가 모호해진다.

연구진은 이 문제를 풀기 위해 구조화된 상호작용 그래프로 다중 객체를 제어하는 그래프 조건부 이미지-투-비디오 생성 모델 GraphVid를 제시했다. 동시에 관계 정보를 담은 대규모 상호작용 중심 영상 데이터셋 GraphVid-Bench도 함께 구축해, 상호작용을 인식하는 영상 생성 모델의 학습을 뒷받침했다.

## 2. Motion-I2V 등 기존 궤적 기반 모델과 비교하면 얼마나 나아졌나?

GraphVid는 기존 모션 제어 모델보다 훨씬 적은 학습 데이터와 학습 파라미터로도 아래와 같은 화질·제어력 개선을 보였다.

| 지표 | Motion-I2V | GraphVid |
| --- | --- | --- |
| FID | 기준값 | 최대 39.9%↓ |
| FVD | 기준값 | 최대 37.6%↓ |
| PSNR | 9.87 | 15.98 |
| SSIM | 0.38 | 0.61 |

FID·FVD는 생성 영상이 실제 영상 분포와 얼마나 가까운지를 보는 지표로, 낮을수록 좋다. PSNR·SSIM은 화질과 구조적 유사도를 보는 지표로, 높을수록 좋다. 네 지표 모두 GraphVid 쪽으로 방향이 일관됐다.

> **요약**: 더 적은 데이터·파라미터로도 화질(PSNR·SSIM)과 분포 일치도(FID·FVD)를 동시에 개선했다.

## 3. 상호작용 그래프로 어떻게 영상을 제어하나?

GraphVid는 사용자가 그린 개별 궤적 대신, 객체 간 관계를 구조화한 상호작용 그래프를 입력으로 받는다. 이 그래프를 조건으로 삼아 이미지 한 장을 영상으로 변환하는 방식이다. 학습에는 관계 주석이 달린 GraphVid-Bench 데이터셋을 사용해, 모델이 객체 개별 움직임뿐 아니라 객체 사이의 상호작용 패턴 자체를 학습하도록 했다.

이 구조 덕분에 사용자는 객체마다 궤적을 일일이 그리지 않고도 여러 객체의 관계를 지정하는 것만으로 영상 생성을 제어할 수 있다. 연구진은 이런 구조화된 의미 인터페이스가 제어 가능한 영상 생성의 새로운 패러다임이 될 잠재력이 있다고 평가한다.

> **팁**: 장면에 등장하는 객체 수가 많거나 서로 가려지는 상황일수록, 궤적을 일일이 그리는 방식보다 관계 그래프 방식의 이점이 커진다.

## 4. 실무에서는 무엇을 주의해야 하나?

GraphVid는 기존 모션 제어 모델보다 적은 학습 데이터와 파라미터로 이 정도 개선을 냈다는 점에서 효율성 면의 강점이 뚜렷하다. 다만 초록에 공개된 수치는 Motion-I2V라는 특정 비교 대상, 그리고 GraphVid-Bench라는 자체 구축 데이터셋 기준이라는 점은 감안해야 한다. 다른 궤적 기반 모델이나 범용 벤치마크에서의 성능은 별도로 확인이 필요하다.

- **Q. 궤적을 직접 그리지 않아도 되나?**
  - **A.** 그렇다. 객체별 궤적 대신 구조화된 상호작용 그래프로 다중 객체의 움직임과 관계를 지정한다.
- **Q. 학습 비용은 기존 모델보다 큰가?**
  - **A.** 아니다. 기존 모션 제어 방법보다 훨씬 적은 학습 데이터와 학습 파라미터로 더 나은 결과를 냈다.
