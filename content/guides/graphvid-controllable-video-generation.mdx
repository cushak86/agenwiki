GraphVid는 텍스트나 궤적 대신 구조화된 인터랙션 그래프로 다중 객체의 움직임을 제어하는 이미지-투-비디오 생성 모델이다. 기존 모션 제어 기법인 Motion-I2V와 비교해 FID를 최대 39.9%, FVD를 최대 37.6% 낮췄고 PSNR은 9.87에서 15.98로, SSIM은 0.38에서 0.61로 개선됐다. 더 적은 학습 데이터와 더 적은 파라미터로 이 결과를 냈다는 점이 특징이다.

| 항목 | 수치 |
| --- | --- |
| FID 개선폭 | 최대 39.9% ↓ |
| FVD 개선폭 | 최대 37.6% ↓ |
| PSNR 변화 | 9.87 → 15.98 |
| SSIM 변화 | 0.38 → 0.61 |

다중 객체가 등장하는 영상을 만들 때, 텍스트 프롬프트만으로는 "누가 무엇과 어떻게 상호작용하는지"를 정확히 지정하기 어렵다. 궤적(트래젝토리) 기반 제어는 이를 보완하지만, 사용자가 객체마다 정확한 이동 경로를 직접 그려야 해서 장면이 복잡해질수록 다루기 힘들어지고, 객체가 겹치거나 가려지면 궤적 자체가 모호해진다.

GraphVid는 이 문제를 인터랙션 그래프라는 구조화된 인터페이스로 접근한다. 픽셀 움직임을 일일이 지정하는 대신, 객체와 객체 간 관계를 그래프 형태로 조건 입력해 영상을 생성한다. 연구진은 이런 관계 정보를 학습시키기 위해 대규모 인터랙션 중심 비디오 데이터셋 GraphVid-Bench도 함께 공개했다.

## GraphVid란 무엇인가?

GraphVid는 그래프로 조건화된 이미지-투-비디오 생성 모델이다. 그래프의 노드는 장면 속 개별 객체를, 엣지는 객체 간 관계나 상호작용을 나타낸다. 사용자는 각 객체의 이동 궤적을 픽셀 단위로 그리는 대신, 어떤 객체가 어떤 객체와 어떤 관계로 움직이는지를 구조화된 그래프로 지정하면 된다.

이런 방식은 장면이 복잡해지거나 객체 수가 늘어나도 상대적으로 다루기 쉽다. 궤적 기반 제어처럼 화면상의 정확한 좌표를 매 프레임 지정할 필요가 없고, 객체가 서로 겹치거나 잠시 가려지는 상황에서도 관계 자체는 명시적으로 유지되기 때문이다.

## 기존 모션 제어 방식과 얼마나 다른가?

연구진은 대표적인 모션 제어 기법인 Motion-I2V를 기준선으로 삼아 GraphVid를 비교했다. 네 가지 지표 모두에서 GraphVid가 우위를 보였다.

| 지표 | Motion-I2V | GraphVid |
| --- | --- | --- |
| FID | 기준 | 최대 39.9% 개선 |
| FVD | 기준 | 최대 37.6% 개선 |
| PSNR | 9.87 | 15.98 |
| SSIM | 0.38 | 0.61 |

> **요약**: GraphVid는 더 적은 학습 데이터와 더 적은 파라미터로도 화질(FID·FVD·PSNR·SSIM)과 제어력을 동시에 끌어올렸다.

주목할 점은 이 개선이 더 많은 자원을 투입해서 나온 결과가 아니라는 것이다. 논문에 따르면 GraphVid는 기존 모션 제어 방법들보다 학습 데이터와 학습 가능한 파라미터 수가 더 적다. 즉 구조화된 조건 정보 자체가 학습 효율을 높이는 데 기여했다는 뜻이다.

## 인터랙션 그래프는 어떻게 작동하나?

GraphVid의 핵심은 그래프 조건을 영상 생성 과정에 결합하는 구조다. 연구진은 관계 주석이 달린 대규모 비디오 데이터셋 GraphVid-Bench를 새로 구축해, 모델이 "이 객체와 저 객체가 이런 관계로 움직인다"는 정보를 직접 학습하도록 했다. 기존 모션 제어 연구들이 픽셀 움직임을 제약하는 저수준 신호(궤적, 모션 벡터 등)에 의존했다면, GraphVid는 객체 간 관계라는 더 상위 수준의 시맨틱 정보를 조건으로 사용한다.

이 접근은 장면 복잡도가 늘어날 때 특히 유리하다. 궤적 기반 제어는 객체 수에 비례해 사용자가 그려야 할 궤적도 늘어나지만, 그래프 기반 제어는 관계를 추가하는 방식으로 확장할 수 있어 상대적으로 부담이 적다.

## 실무에서 무엇을 주의해야 하나?

- **Q. GraphVid는 궤적 기반 제어를 완전히 대체하나?**
  - **A.** 논문은 GraphVid를 궤적 기반 제어의 대안으로 제시하며, Motion-I2V 대비 우수한 결과를 보였다고 밝힌다. 다만 논문에서 비교한 기준선은 Motion-I2V이며, 다른 궤적 기반 기법 전반과의 비교는 초록에서 확인되지 않는다.
- **Q. 사용자가 그래프를 직접 만들어야 하나?**
  - **A.** 초록에는 인터랙션 그래프를 조건으로 입력한다고만 설명돼 있어, 그래프 작성이 자동화되는지 수동인지는 이 초록만으로는 확인되지 않는다.
- **Q. GraphVid-Bench는 무엇에 쓰이나?**
  - **A.** 관계 주석이 달린 대규모 인터랙션 중심 비디오 데이터셋으로, 인터랙션을 인식하는 영상 생성 모델을 학습시키기 위해 새로 구축됐다.

> **주의**: 이 글의 수치는 논문 초록에 보고된 Motion-I2V 대비 상대 개선폭이다. 다른 최신 모션 제어 기법과의 비교나 절대적인 체감 품질은 초록만으로 판단하기 어렵다.
